Understanding Box-Sizing

Both boxes below share the exact same CSS rules for width (260px), padding (30px), and border (6px). However, their total rendered dimensions differ significantly depending on the box-sizing model used.

content-box (Default)

Total width = Width + Padding + Borders. This box expands outward because padding and borders are added on top of the specified width.

border-box

Total width remains exactly 260px. Padding and borders are calculated inside the specified width rather than adding to it.
